# 📦 AssetVault

**AssetVault** is a simple and professional Android application for managing and tracking personal assets in one place.

The application allows users to store information about their assets such as **appliances, vehicles, property, and other valuable items**, along with important details like purchase information and warranty status.

## 📌 About the Project

Managing different assets manually can make it difficult to remember important information such as purchase dates, prices, warranty periods, and asset details.

**AssetVault** provides a centralized digital solution where users can add and manage their assets easily.

The main goal of the project is to provide a **simple, user-friendly, and organized asset management application**.

---

## 🎯 Objectives

* Store asset information digitally.
* Manage multiple assets from one application.
* Keep important purchase details organized.
* Track warranty information.
* View the total number of stored assets.
* Provide a simple and easy-to-use dashboard.
* Reduce the need for maintaining asset information manually.

## ✨ Features

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/AssetVault.git
```

### 2. Open in Android Studio

Open **Android Studio** and select:

```text
File → Open → AssetVault
```

### 3. Wait for Gradle Sync

Allow Android Studio to download and configure the required dependencies.

### 4. Connect a Device

You can use:

* Android Emulator
* Physical Android Device

### 5. Run the Application

Click the **Run ▶ button** in Android Studio.

## 💡 Example Use Case

A user purchases a new refrigerator.

Instead of keeping the information in a notebook, the user can add it to AssetVault:

```text
Asset Name: Refrigerator
Category: Appliance
Purchase Date: 10-09-2026
Purchase Price: ₹35,000
Warranty: 2 Years
```

The asset is then stored in the application and the dashboard asset count is updated.
